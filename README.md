# 5UserApp

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 18.2.7.

Aplicación de adminitración de usuarios, desarrollado en angular usando Redux, con backend desarrollado en Spring Boot.
Puedes registrar usuarios normales como usuarios administrativos para acceder a distintas funciones en la aplicación, esto usando JWT para la seguridad.

Los administrativos pueden acceder al crud completo e iniciar sesión, mientras los usuarios normales, solo pueden iniciar sesion y ver los usuarios correspondientes registrados, pero no pueden modificar, agregar o eliminar.
